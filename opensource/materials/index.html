LGPL Materials Package

Corresponding source code, patches, license texts, build & linking instructions and relinking materials for the LGPL components used by the RUKIK smart keyboard (see Open Source Licenses). Every file of the package is listed below and can be downloaded individually. The upstream source code itself is obtained with fetch-sources.sh from the public repositories named in MANIFEST.md. To receive the whole package as a single archive, email hello@rukik.com and we will provide it within 30 days.
