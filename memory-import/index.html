内部入口 · 仅限创始人账号。导入的记忆绑定您的 RUKIK 账号，其他任何人（包括其他用户与专家）都看不到。

导入说明

导入的是您导出时点之前的聊天记录快照。导入完成后，在任意设备登录同一 RUKIK 账号，打开『问 RUKIK』即可调用这段历史。

微信的新消息不会自动同步。想更新时，重新导出并再次导入即可，系统会自动跳过已导入的记录、只补新的。

文件只在您的浏览器内存中解开并上传到您账号名下的记忆库；本页面不保存任何副本，关掉页面即不留残留。

在电脑浏览器里看到值得记住的网页内容，也可以用 Chrome 扩展随手存进 RUKIK 记忆：Chrome 扩展：RUKIK · 一键记忆

登录

使用创始人账号登录（邮箱验证码或密码均可）。其他账号登录后，数据接口会拒绝访问。

没有访问权限

这个账号不在允许名单里，数据接口已拒绝访问。

您的微信在哪个设备上？

选一下，我们按您手边设备给最省事的导入方式。

当前可用

Rukik Mac 导入助手已在本机验证：在 Mac 微信里打开要珍藏的会话，多选消息 →「合并转发」→「其他应用」→ 选 Rukik，记录先到助手里本机预览、由您确认；助手目前为本机验证形态、尚未对外分发。已经导出的 ZIP 或 TXT，也可以回到本页在下方直接上传导入。

网页导入

Windows 暂无专用的导入工具，本页的网页上传就是 Windows 的导入通道：手上已有导出的 ZIP 或 TXT 聊天记录包的话，切到「Mac 电脑」一栏、用下方上传即可导入，效果完全一样；还没有导出包的话，先在 Mac 上导出再上传。

当前可用

在 iPhone 微信里打开要珍藏的内容——一条文件消息（如 PDF、ZIP）、一篇公众号文章或一张图片——点「…」→「用其他应用打开」→ 选 Rukik；内容先暂存在手机上，再打开 Rukik App（需 2.58.0 版），在「我的专业团队 → 知识库」顶部的「待导入」入口里预览并确认，确认后才导入您的记忆。注意：一次分享一个文件；微信里多选后的「合并转发」不会进入系统分享、这条路走不通，整段聊天记录请仍用 Mac 导出后在本页上传；语音消息在微信里没有分享出口，暂不支持。

上传聊天记录

选择从微信导出的 ZIP 包（内含聊天记录 TXT 与图片、视频、文件），或直接选择 TXT 文件。ZIP 在浏览器内解开，只把文本与附件清单发给服务端解析。
